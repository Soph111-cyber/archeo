🏺 ArchaeoInfer: AI for Archaeological Site Prediction

## 📌 Overview
ArchaeoInfer is an AI-powered system designed to predict potential archaeological sites using geospatial data, environmental features, and probabilistic modeling.

This project integrates machine learning, spatial analysis, and domain-inspired heuristics to assist archaeologists in identifying high-probability excavation locations.

---

## 🚀 Key Features
- 📍 Predictive modeling of potential archaeological sites
- 🌍 Geospatial feature integration (terrain, water proximity, etc.)
- 🧠 Machine learning + probabilistic scoring
- 📊 Interactive visualization with Streamlit
- 🌐 Bilingual interface (English + Chinese)

---

## 🧮 Methodology
The system combines:
- Feature-based scoring (environmental + spatial factors)
- Probabilistic weighting models
- Heuristic rules inspired by archaeological patterns
- Optional machine learning extensions

---

## 💡 Motivation
Traditional archaeological discovery is often time-consuming and resource-intensive.

This project explores how AI and mathematical modeling can:
- Reduce uncertainty
- Improve efficiency
- Enable data-driven exploration of cultural heritage
